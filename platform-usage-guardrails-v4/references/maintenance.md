# Maintenance and review

Guardrails must be reviewed when:

- A contract is renewed or amended.
- Vendor pricing changes.
- Billing units or quotas change.
- A connector is added or replaced.
- API endpoints change.
- A new content set is introduced.
- Usage unexpectedly exceeds estimates.
- A shared allowance is exhausted.
- A new team or department begins using the platform.
- Data storage or redistribution rules change.

For every update:

1. Recheck the relevant evidence.
2. Record what changed.
3. Update the cost model.
4. Review approval thresholds.
5. Update the Claude-facing rules.
6. Regenerate affected team documentation.
7. Record the new version and verification date.

Do not silently carry old assumptions into a new policy.
